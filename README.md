# Song zu Noten

Eine einfache Web-App, die eingegebene Notennamen grafisch im Violinschlüssel darstellt. Gib eine Folge von Noten wie `C4 D4 E4/8` ein und klicke auf "Noten anzeigen", um die Noten inklusive Notennamen unterhalb der Notenzeile anzuzeigen.

## Nutzung

Öffne die Datei [`index.html`](index.html) in einem aktuellen Browser mit Internetverbindung. Die Notendarstellung erfolgt mit [VexFlow](https://www.vexflow.com/) über ein CDN.
